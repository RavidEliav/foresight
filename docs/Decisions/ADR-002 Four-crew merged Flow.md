# ADR-002 Four-crew merged Flow

## Context
The official brief requires Analyst + Scientist crews; the semiconductor subject adds Investigation + Report teams.

## Options considered
- Official two crews only
- Subject two teams only
- Merge all four

## Decision
One CrewAI Flow with four crews: Data Analyst, Data Scientist, Investigation, Engineering Report.

## Consequences
Covers both documents. If time runs short, Investigation merges into Report. Pending the professor's feedback on the proposal.
